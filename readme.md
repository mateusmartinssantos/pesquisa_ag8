# Pesquisa de Atendimento ao Cliente - ETEC

A atividade consiste no desenvolvimento de um programa em **Python** utilizando estruturas de repetição e decisão. O objetivo é coletar e analisar o retorno de uma pesquisa de satisfação de atendimento ao cliente, contabilizando os resultados obtidos de forma automatizada.

Este projeto foi desenvolvido como parte das atividades acadêmicas da **ETEC (Escola Técnica Estadual)**.

---

## 📋 Enunciado do Problema

Desenvolver um programa em Python utilizando a estrutura de repetição para coletar e exibir o retorno de uma pesquisa de atendimento ao cliente.
O programa deve solicitar a digitação do nome, idade e opinião do entrevistado sobre o atendimento prestado, sendo:
* **1:** EXCELENTE
* **2:** BOM
* **3:** RUIM

A pesquisa deve ser feita com 50 entrevistados. Ao final, o programa deverá exibir na tela:
* **a)** Quantidade de respostas “EXCELENTE”
* **b)** Quantidade de respostas “RUIM”

*Nota: Realizar testes iniciais com 10 entrevistados para validar o funcionamento do programa.*

---

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o [Python](https://python.org) instalado em sua máquina.
2. Baixe o arquivo `pesquisa.py` deste repositório ou clone o projeto:
   ```bash
   git clone https://github.com
   ```
3. Abra o terminal ou prompt de comando na pasta do arquivo e execute:
   ```bash
   python pesquisa.py
   ```
